# MAX CARD FINANCE PRO

Arabic offline-first financial ledger prototype for MAX CARD.

**WARNING:** Browser localStorage is not secure accounting storage. Use test data only. Closing is an app-level lock, not tamper-proof. No guaranteed 1 AM background notifications in a browser. No native APK in this repository. Do not upload financial backups to public GitHub.

Start balance $150; accounting cycles 17th–16th; USD.

To deploy: Settings > Pages > Source: GitHub Actions. Then push to main or manually run Deploy MAX CARD website.
